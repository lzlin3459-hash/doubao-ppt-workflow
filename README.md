# Doubao PPT Workflow

## 豆包工作流：PPT 生成实战

> **从数据到观点的优雅跃迁 —— 让 AI 先读懂数据，再替你表达。**

一份基于「先分析 · 后制作」方法论的人机协同 PPT 生成 Skill。它拒绝让 AI 机械地「换皮」出片，而是要求 AI 先以数据分析师的身份产出编号洞察，再由人选定叙事重点，最后才生成汇报级 PPT。专业设计的核心准则被固化进工作流：**每页只讲一个论点**。

---

## 缘起

传统的 AI 生成 PPT，只是把内容套进模板——它「会排版」，却「没观点」。

真正的汇报制作是三重身份的分工协作：**数据分析师**（提炼洞察）→ **设计师**（构建叙事）→ **文案**（人性化表达）。本 Skill 将这三重能力与人的判断力结合，接管从材料到成品的全部中间环节，同时把两个关键决策权保留在人手中：**选什么重点、怎么对谁说**。

---

## 安装（给使用者的步骤）

1. **获取代码**：点击仓库右上角 `Code` → `Download ZIP`，或终端执行：

   ```bash
   git clone https://github.com/lzlin3459-hash/doubao-ppt-workflow.git
   ```

2. **放入技能目录**：将解压后的 `doubao-ppt-workflow` 文件夹**整体**复制到豆包 Agent 环境的用户技能目录：

   - Windows 默认位置：`workspace/.user_skills/`
   - 必须保持目录结构不变：`doubao-ppt-workflow/SKILL.md`

3. **新开会话**：重启/新开一个豆包会话后，向 AI 提供数据表并说明汇报场景（例如「把这份电商复盘数据做成周会 PPT」），技能自动生效。

4. **试用样例**：可用 `examples/sample_ecommerce_review.csv` 快速跑通全流程。

> 说明：本 Skill 依赖豆包 Agent 环境的 PPT 生成与图表能力；纯对话场景下无法生效。

## 方法论：五步 SOP

| 步骤 | 动作 | 关键约束 |
| --- | --- | --- |
| 01 | 输入材料 | 完整读取数据表/文档，弄清结构与计算口径 |
| 02 | 先分析后制作 | 产出数据分析结果与编号洞察（事实/问题 + 建议，标注来源）；不可跳步 |
| 03 | 人工定重点 | 从洞察中选定 2-3 个核心方向（支持引用「洞察4、5」） |
| 04 | 生成 PPT 初稿 | 每页单论点、结论式标题、高级图表、自动配讲稿 |
| 05 | 人工审核微调 | 逐页核对数据，语气从「危言耸听」收敛为温和表述 |

### 两个决策点

- **是否已有明确观点？** 有 → 直接定重点；无 → 先让 AI 分析找出问题。
- **汇报对象是谁？** 老板看结论（结论式标题）；专家看数据（保留交互图与明细）。

---

## 设计原则：不可妥协的红线

- **数据溯源** — 每个数字必须来自输入材料或可复现计算，PPT 中标注来源，无来源的数字不写入。
- **数据安全** — 涉密数据先脱敏，主动提醒避免上传机密经营数据到第三方。
- **幻觉核查** — AI 洞察与图表数字必须与原始数据一致，交付前人工逐页核对；错误占比超 10% 则全稿复核。
- **Prompt 基线** — 生成指令复用技能模板，关键输出存档，模型变更后重新验证效果。
